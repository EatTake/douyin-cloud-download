# Changelog

All notable changes to this project are documented here. The project uses Semantic Versioning.

## [1.0.0] - 2026-09-10

### Added
- Formal Windows x86_64 and Linux x86_64 installation/maintenance controller.
- Pinned DouK, Quark and Baidu upstream dependencies with reviewed integrity metadata.
- Resumable download jobs, atomic manifests, runtime integrity checks and dual-cloud completion rules.
- Persistent release snapshots, rollback commands, state-schema migrations, stable error codes and sanitized diagnostics.

### Changed
- Updated the vendored DouK runtime to `df8aced70e476ae3330fa913186f3207b4843201`.
- Updated Quark Skill to `1.0.19` and Baidu Skill to `v1.7.5`.
